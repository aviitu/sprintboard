# Sprintboard

Código-fonte do artifact **Sprintboard** publicado no claude.ai.

- `index.html` – página principal
- `css/` – estilos (base, temas, animações, módulos)
- `js/` – lógica (kanban, tester, keeper, thinker, patch notes, assistente de IA)

> O app depende do runtime de artifacts do claude.ai (banco compartilhado, usuário logado, Google Docs/Drive). Abrindo o `index.html` fora dele, essas partes não funcionam.
